# Changelog

## 1.0.0rc1

- Exclusive OS-managed ownership of each data directory; an occupied HTTP port is detected before starting application workers.
- Graceful termination requests cancellation, pauses the queue and waits for active workers.
- Strict configuration types, actionable CLI errors and explicit full-folder authorization for terminal monitoring.
- Offline configuration/extension checks and consistent SQLite backups that refuse to overwrite existing files.
- Immediate investigation button locking and separate UI handling of expired sessions and missing jobs.
- MCP retains administrator-configured evidence plugins and their check modes.
- Release acceptance remains pending for live models, IMAP, PostgreSQL, Windows/macOS and rendered-browser accessibility.

## 0.6.0

- Semantic applicability judgments for conditional checks in any message language, with conservative handling of missing, uncertain or withheld-text assessments.
- Unified plugin metadata for model tools, check settings, previews and completion validation.
- Administrator investigation requirements and generic SQLite/PostgreSQL evidence queries over custom schemas.
- Read-only SQLite authorization, query/result limits, bound parameters and local pseudonym resolution.
- Generic specialist focus and configuration provenance in reports.
- Centralized EN/CZ translations, dynamic query controls and a database source editor.
- Multilingual live acceptance command and database/semantic regression tests.

## 0.5.0

- Separate review, monitoring, history and settings views with a source chooser and safe message-text display.
- Draft-based model discovery and connection verification, scoped credentials, local-server presets and visible credential state.
- Consistent host-restricted verdicts and recommendations with recorded analysis scope.
- Reconnect active investigations after reload or temporary transport failure.
- Stable message references, linked queue reports, indexed pagination and bounded interactive IMAP searches.
- Explicit whole-folder scope, mailbox preflight, queue waiting states and faster bounded discovery.
- Check profiles, missing-reference guidance and validation of check/call-limit combinations.
- Updated EN/CZ installation and operation instructions.

## 0.4.0

- Configurable check rules and host-generated completeness reports.
- Dedicated prompt-injection indicators and five exported demo emails.
- Durable IMAP queue with cursor recovery, fenced claims, retries, rate/concurrency limits and pagination.
- Shared model budgets, cancellation, model discovery and readable report history.
- Runtime skills with provenance, bounded specialists and IMAP XOAUTH2 token authentication.
- Single-message MCP evidence tools and guarded completion for external AI harnesses.

## 0.3.1

- Show only provider-relevant connection fields; preserve separate endpoint drafts for local and compatible providers.
- Hide external-processing consent for local AI and quarantine destination until quarantine is enabled.
- Exclude hidden fields from submission and clear unsaved API keys and consent when switching providers.

## 0.3.0

- Added author and language-specific support links.
- Simplified browser-first startup with Python version checks and separate EN/CZ installation guides.
- Grouped optional mailbox settings and fixed message selection during analysis and consent visibility after provider changes.
- Added host checks against premature LOW_RISK completion.
- Added an optional custom AgentDojo evaluation suite; live model evaluation remains pending.

## 0.2.0

- Simplified the review interface and moved Reload next to the AI connection controls.
- Added shared coding-assistant instructions and Claude Code/Cursor entry points.
- Added a source-linked developer guide, a tool activation recipe, and harness/provider extension documentation.
- Documented the implementation boundaries and acceptance criteria for runtime skills and subagents; these are not runtime features in this release.

## 0.1.0

- Initial email investigation agent with native model tool selection, local evidence tools, IMAP and EML input, demo messages, protected outbound data, approval-bound quarantine and an English/Czech interface.
