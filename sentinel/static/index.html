How to create a preset + example

Saving the form updates current settings only; it does not create or modify a preset. Create .local-presets/my-local.toml beside the active sentinel.toml, paste the example below and replace the mailbox details. Reload this page to see it in the list. Only supplied settings change; other settings remain as they are.

provider = "local"
base_url = "http://127.0.0.1:1234/v1"
model = "openai/gpt-oss-20b"
imap_host = "mail.example.com"
imap_port = 993
imap_user = "user@example.com"
imap_folder = "AI-review"
imap_auth = "password"
allow_external = false
allow_quarantine = false

Do not put passwords or API keys in TOML. To restore an IMAP password, create my-local.credentials.json beside the preset with the contents below and put the password in mailbox.secret in the same private directory. Keep these files local and restrict their permissions. The .local-presets directory is excluded from Git.

{"imap_password_file":"mailbox.secret"}
